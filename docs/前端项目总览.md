# NoI JMUI — 前端项目总览与管理

> **NoI JMUI**（鲸幕 UI）：SillyTavern 角色卡**通用前端框架**。
> 所有角色卡的界面（状态栏、未来的更多组件）都基于本框架构建，统一维护。

## 定位

- **一个框架，多卡复用**：界面代码与项目变量完全解耦，各卡只写配置（展示字段/交互/图鉴/主题）
- **能力**：展示（进度条/徽章/星级）、交互（按钮/选项/滑块/输入/剧情选项）、图鉴（分阶段立绘+解锁+密钥）、设置（主题/字号/密度/立绘）、图片、MVU 双向同步
- **技术栈**：Vue 3 + Pinia + webpack（tavern_helper_template 生态），CDN 发布（jsdelivr testingcf 镜像）

## 目录组织

```
src/
├── 通用/状态栏/          ← JMUI 核心组件库（勿改！所有项目复用）
│   ├── types.ts           配置/主题类型（数据契约）
│   ├── theme.ts           默认主题 + 预设（宝可梦/温馨家庭/暗色夜行等）
│   ├── useSettings.ts     设置与解锁状态（localStorage 持久化）
│   ├── unlock.ts          解锁条件判定（阈值/等值/组合）
│   ├── store.ts           defineMvuDataStore 封装（保真 schema）
│   └── components/        StatusSection/ProgressBar/EnumBadge/StageImage/
│                          GalleryPanel/SettingsModal/ActionButton/ChoiceGroup/
│                          SliderInput/TextInput/LockInput/...
├── 接入示例/              ← 演示接入（基于 系统/凯瑟琳/小胖 变量）
├── 全家亲子游/            ← 项目 A：完整 MVU 样板（schema+世界书+脚本+前端）

├── 绿母绿妹NTL/           ← 项目 C（NTL 卡）

```

## 新卡接入流程（五步）

1. **建目录**：复制 `src/接入示例/界面/状态栏/` → `src/{卡名}/界面/状态栏/`
2. **变量**：`schema.ts`（从项目复制）+ `世界书/变量/` 四件套 + `脚本/变量结构/`（注册）——详见 `docs/MVU制卡流程.md`
3. **配置**：`config.ts`（展示/交互字段）+ `gallery.ts`（图鉴/密钥/立绘，可选）
4. **入口**：`index.ts`（等 Mvu 就绪）+ `App.vue`（组装 StatusBar/StatusPanel + SettingsModal）
5. **发布**：`pnpm build` → 提交 → push → **手动触发 CI**（`gh workflow run bundle.yaml`）→ CDN 地址写回项目正则

## 新增通用组件规范（再搓前端时遵守）

- **位置**：`src/通用/状态栏/components/`（或按用途新建 `src/通用/{组件名}/`）
- **样式**：只用 `var(--sb-*)` 变量（主题联动）；功能语义命名
- **配置**：行为由纯数据配置声明（可 JSON/YAML），不写死项目字段
- **状态**：设置/解锁走 `useSettings`（localStorage），交互写 `store.data`（MVU 自动同步）
- **测试**：纯逻辑（路径解析/解锁/配置校验）配 `node --test` 单测
- **文档**：新能力同步更新 `docs/通用状态栏接入文档.md`
