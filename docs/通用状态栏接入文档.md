# 通用状态栏接入文档

通用前端状态栏模板：**界面代码与项目变量结构完全解耦**，可复用于任意 MVU 角色卡项目。

- 变量读取：运行时按 MVU 变量 `stat_data` 的点分路径动态读取（`defineMvuDataStore`）
- 展示配置：哪些字段、分组、标签、图标、映射，全部由外部配置传入，界面零硬编码
- 主题：CSS 变量 + 主题配置对象，默认「宝可梦卡」风格，支持按项目覆盖
- **交互**：按钮 / 选项组 / 滑块 / 输入框，行为（写变量 or 发消息触发 AI）由配置声明
- **配图**：图片字段 / 区块图 / 面板顶部图 / 背景图，URL 三种来源（静态 / 变量映射 / 变量直存）

## 快速接入（三步）

### 第一步：复制演示骨架

把 `src/接入示例/界面/状态栏/` 整个目录复制为 `src/{你的项目}/界面/状态栏/`。

### 第二步：写展示配置 `config.ts`

按你的变量路径重写 `config`。**界面代码零改动**，只改配置。

```ts
import type { StatusBarConfig } from '../../../通用/状态栏/types';

export const config: StatusBarConfig = {
  title: '当前状态', // 可选，顶部标题
  sections: [
    {
      id: 'system',
      label: '系统', // 区块标题（宝可梦主题下显示为 ━━━【系统】━━━）
      icon: '📍', // 区块图标（符号字符或 fa-* 类名）
      collapsible: true, // 可选，默认 true
      defaultCollapsed: false, // 可选，默认 false
      fields: [
        // ↓ text：纯文本（空值显示 fallback，默认 '—'）
        { type: 'text', path: '系统.当前地点', label: '地点', icon: '📍' },

        // ↓ enum：枚举值 → 彩色徽章
        {
          type: 'enum',
          path: '凯瑟琳.沦陷阶段',
          label: '沦陷阶段',
          mapping: {
            纯真期: { color: '#66bb6a' }, // 徽章底色（自动选可读文字色）
            试探期: { label: '试探', color: '#fdd835', icon: '⚠' }, // 可改文案/加图标
            沉沦期: { color: '#ff8a65' },
            堕落期: { color: '#e53935' },
          },
        },

        // ↓ progress：数值进度条（min/max 默认 0-100）
        {
          type: 'progress',
          path: '小胖.欲望值',
          label: '欲望值',
          showValue: true, // 显示 30/100，默认 true
          thresholds: [
            // 阈值配色：按 min 从大到小，取第一个 value >= min
            { min: 66, color: '#e53935' },
            { min: 33, color: '#f9a825' },
            { color: '#2e7d32' }, // 兜底色
          ],
        },

        // ↓ number：数字（可选 precision 小数位）
        { type: 'number', path: '小胖.欲望值', label: '欲望', precision: 1 },

        // ↓ stars：星级（★★★★☆，value/max 取整）
        { type: 'stars', path: '凯瑟琳.身体开发度', label: '开发星级', max: 5 },
      ],
    },
  ],
};
```

### 第三步：入口接线

1. `schema.ts`：把项目的 `schema.ts` 复制进来（两处副本保持一致）
2. `store.ts`：默认 `createStatusBarStore({ schema: Schema })`；不想传 schema 时用 `createStatusBarStore()`（保真模式，见下方注意事项）
3. `theme.ts`：可选，主题覆盖（见下）
4. `App.vue` / `index.ts` / `index.html`：保持演示版即可

## 配置参考（JSON / YAML 形式）

配置是纯数据，也可以从 JSON/YAML 加载（配合 `parseStatusBarConfig` 校验）：

```json
{
  "title": "当前状态",
  "sections": [
    {
      "id": "system",
      "label": "系统",
      "icon": "📍",
      "collapsible": true,
      "fields": [
        { "type": "text", "path": "系统.当前地点", "label": "地点", "icon": "📍" },
        { "type": "enum", "path": "系统.当前视角", "label": "视角", "mapping": { "丈夫": { "color": "#3b4cca" } } },
        { "type": "progress", "path": "凯瑟琳.身体开发度", "label": "开发度", "min": 0, "max": 100, "showValue": true }
      ]
    }
  ]
}
```

```yaml
title: 当前状态
sections:
  - id: system
    label: 系统
    icon: "📍"
    fields:
      - type: text
        path: 系统.当前地点
        label: 地点
        icon: "📍"
      - type: enum
        path: 凯瑟琳.沦陷阶段
        label: 沦陷阶段
        mapping:
          纯真期: { color: "#66bb6a" }
          堕落期: { color: "#e53935" }
      - type: progress
        path: 小胖.欲望值
        label: 欲望值
        showValue: true
```

> 字段类型一览（展示）：`text` / `number` / `progress` / `enum` / `stars`
> 字段类型一览（交互与图片）：`image` / `action` / `choice` / `slider` / `input`
> 字段公共属性：`path`（必填，点分路径）、`label`（必填）、`icon`（可选）、`fallback`（可选，空值占位文案）。

## 交互字段（V2）

交互控件的行为全部由纯数据配置声明（可 JSON/YAML 表达），界面只负责执行。

**两种行为（action 与每个 choice 选项共用）：**

| 行为 | 效果 | 说明 |
| --- | --- | --- |
| `{mode:'variable', path, delta?/value?}` | 写 MVU 变量 | 改 `store.data` → `defineMvuDataStore` 自动写回楼层变量 → 世界书注入 → AI 下一轮感知 |
| `{mode:'message', content, slash?}` | 发消息触发 AI | `createChatMessages` 发出用户消息 + `triggerSlash`（默认 `/trigger`），直接推进对话 |

```ts
// action：按钮
{
  type: 'action', label: '好感+5', icon: '💗',
  action: { mode: 'variable', path: '角色.好感度', delta: 5, toast: '好感度 +5' },
}
// action：发消息
{
  type: 'action', label: '打招呼',
  action: { mode: 'message', content: '我轻轻打了个招呼', toast: '已发送' },
}

// choice：选项组（单选）
{
  type: 'choice', label: '怎么回应？',
  options: [
    { label: '拥抱她', action: { mode: 'message', content: '我轻轻抱住了她' } },
    { label: '好感+10', action: { mode: 'variable', path: '角色.好感度', delta: 10 } },
  ],
}

// slider：滑块（拖动写变量，防抖 300ms）
{ type: 'slider', label: '心情', path: '角色.心情值', min: 0, max: 100, step: 5, showValue: true },

// input：文本输入（enter 提交 / blur 失焦提交 / live 实时写入）
{ type: 'input', label: '留言', path: '系统.留言', commitOn: 'enter', maxLength: 50 },
```

> 注意：交互字段需要给 `<StatusBar>` 传 `store`（如 `:store="useDataStore()"`），
> 否则 variable 模式的控件会禁用。message 模式在酒馆助手环境下自动发消息；
> 无酒馆的环境（预览页）降级为 toastr 提示。

## 图片字段（V2）

图片来源三种（`ImageSource`），均支持 `fit`（contain/cover/fill）与 `ratio`（宽高比，如 `16/9`）：

| 来源 | 配置 | 用途 |
| --- | --- | --- |
| static | `{type:'static', url}` | 固定 URL（CDN 直链） |
| mapped | `{type:'mapped', by:'系统.地点', map:{厨房:'…/厨房.png'}}` | 按变量值查表映射：AI 只维护键名（地点），前端映射到图 |
| fromVariable | `{type:'fromVariable', path:'系统.场景图'}` | 变量直接存 URL |

```ts
// 字段级图片
{ type: 'image', label: '场景', source: { type: 'mapped', by: '系统.地点', map: { 厨房: 'https://…/kitchen.png' } }, ratio: '16/9' },

// 区块顶部图（section.image）
{ id: '角色', label: '角色', image: { source: { type: 'static', url: 'https://…/avatar.png' }, ratio: '1/1' }, fields: [...] },

// 面板级图片（config.images）：top=顶部立绘区，background=背景图
images: [
  { id: '立绘', position: 'top', source: { type: 'static', url: 'https://…/hero.png' }, ratio: '16/9' },
  { id: '背景', position: 'background', source: { type: 'mapped', by: '系统.地点', map: { 厨房: 'https://…/bg.png' } } },
],
```

> 图片约定：静态图放项目目录（如 `src/{项目}/图片/`），推送到 GitHub 后经
> `https://testingcf.jsdelivr.net/gh/{用户}/{仓库}/…` 引用；**不内联 base64**。

## 人物立绘图鉴（V3）

人物图片分阶段展示 + 解锁机制 + 密钥彩蛋。配置（`StatusBarConfig.gallery`）：

```ts
gallery: {
  masterKey: 'family2026', // 全局密钥：输入一次解锁全部图鉴（与字段锁共用）
  characters: [
    {
      id: '孙莹', name: '孙莹', icon: '👩',
      images: [
        { id: '孙莹-日常', label: '日常', url: 'https://…/日常.svg' }, // 无 unlock = 默认解锁
        { id: '孙莹-亲昵', label: '亲昵', url: 'https://…/亲昵.svg',
          unlock: { type: 'threshold', variable: '角色.孙莹.好感度', min: 70 } }, // 变量阈值
        { id: '孙莹-沉沦', label: '沉沦', url: 'https://…/沉沦.svg',
          unlock: { type: 'any', conditions: [ { type: 'threshold', variable: '角色.孙莹.好感度', min: 90 }, { type: 'equals', variable: '剧情.阶段', value: '沉沦' } ] },
          key: 'family2026' }, // 单图密钥（可选）
      ],
    },
  ],
},
```

**解锁条件**（`UnlockCondition`，纯数据）：
- `{type:'threshold', variable, min?, max?}`：变量数值区间（`角色.孙莹.好感度 ≥ 70`）
- `{type:'equals', variable, value}`：变量等于某值
- `{type:'all'|'any', conditions: []}`：且 / 或组合

**解锁状态**（localStorage 持久化，`useSettings`）：
- 条件实时判定：达标即解锁
- **永久记录**：达标过一次即永久解锁（`sb:gallery-unlocked`），变量降回也保留
- **密钥**：输入匹配的 key（单图 key / masterKey）即记录（`sb:keys`），同 key 的锁与图共享解锁状态

## 设置界面（V3）

`StatusBarConfig.settings` 启用后，右上角出现 ⚙️ 按钮，弹窗含两个 tab：

| tab | 内容 |
| --- | --- |
| 外观 | 主题预设切换（内置：宝可梦卡 / 温馨家庭 / 暗色夜行）+ 密度三档 + 字号滑块 90-130% |
| 图鉴 | GalleryPanel（角色分组图片网格：锁定遮罩显示条件/密钥输入，解锁可看大图）+ 全局密钥输入 |

- 项目自定义预设：`settings.themePresets: [{ id, label, theme: ThemeOverride }]`
- 设置持久化：`sb:theme` / `sb:density` / `sb:font-scale`（玩家偏好，不写回 MVU 变量）
- 弹窗基于 `vue-final-modal`（免插件模式，样式自备）

## 字段锁（V3）

交互控件（action / choice / slider / input）可加 `lock`，输入密钥解锁后才可交互：

```ts
{
  type: 'action', label: '好感+5',
  action: { mode: 'variable', path: '角色.孙莹.好感度', delta: 5 },
  lock: { key: 'family2026', hint: '输入密钥后可调整' },
}
```

- 锁定态显示 🔒 按钮，点击弹出密钥输入；匹配即解锁（记录到 `sb:keys`）
- 与图鉴共用密钥记录：masterKey 输入一次，字段锁与图鉴全部解锁

## 主题覆盖

主题 = 默认宝可梦卡主题 + 按项目覆盖。只写想改的键：

```ts
// theme.ts
import type { ThemeOverride } from '../../../通用/状态栏/types';

export const theme: ThemeOverride = {
  colors: {
    primary: '#2f3f9f', // 徽章主色
    surface: '#fffdf6', // 面板底色
  },
  radius: { panel: '8px' },
  density: 'compact', // compact | normal | comfortable
};
```

完整主题结构（`src/通用/状态栏/types.ts`）：

| 键 | 说明 |
| --- | --- |
| `colors.primary / accent / success / warning / danger` | 语义色 |
| `colors.surface / surfaceAlt` | 面板 / 次级底色 |
| `colors.text / textMuted / border` | 文字与边框 |
| `colors.progressTrack / progressFill` | 进度条轨道 / 填充 |
| `font.family / sizeSmall / sizeLabel` | 字体族与字号（密度自动控制基础字号） |
| `radius.panel / pill` | 圆角 |
| `density` | 展示密度 |
| `section.dividerChar / headerStyle / bracketLeft / bracketRight / iconCollapsed / iconExpanded` | 分区标题形态（宝可梦风分隔线、折叠图标） |
| `spacing.panelPadding / itemGap / sectionGap` | 间距 |

自定义整体风格时，也可直接写一个完整的 `StatusBarTheme` 传入。后续新增风格字段时，在 `types.ts` 与 `theme.ts` 的 `themeToCssVars` 中同步扩展即可。

## 注意事项

1. **保真模式（推荐）**：`createStatusBarStore()` 不传 schema 时使用保真 schema，不会剥除任何 `stat_data` 字段。`defineMvuDataStore` 轮询时会把解析结果**写回消息变量**，若 schema 声明不全，zod 的 strip 行为会删掉未声明字段 —— 因此只有当你确定项目 schema 完整时才传入 `schema` 选项。
2. **点分路径**：配置里的 `path` 是 `stat_data` 内部的相对路径（如 `系统.当前视角`），不需要 `stat_data.` 前缀；支持任意嵌套层级。
3. **图标**：`icon` 字段传符号字符（如 `❤`）原样渲染；传 `fa-solid fa-heart` 这类以 `fa` 开头的类名则渲染 FontAwesome 图标。
4. **演示配置**：`src/接入示例/` 基于现有项目变量（系统/凯瑟琳/小胖），可作为模板验证与参考，接入新项目时整目录复制。
